# Changelog

All notable changes to the Pirate Calculator project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial pirate-themed calculator implementation
- Basic arithmetic operations (+, -, ×, ÷)
- Pirate mode Easter egg (activated with 7734 sequence)
- Responsive design for mobile and desktop
- Full keyboard navigation support
- Accessibility features with ARIA labels
- Error handling with pirate-themed messages
- Visual animations and hover effects
- High contrast and reduced motion support

### Technical Details
- Vanilla HTML, CSS, and JavaScript (no dependencies)
- CSS Grid layout for button arrangement
- ES6+ JavaScript with class-based architecture
- CSS custom properties for theming
- Comprehensive error handling and input validation
