# 🏴‍☠️ Pirate Calculator

A swashbuckling calculator with a nautical theme and a special pirate mode Easter egg!

## ⚓ Features

- **Full Calculator Functionality**: All basic arithmetic operations (+, -, ×, ÷)
- **Pirate Mode Easter Egg**: Enter `7734` to activate special pirate mode with "ARRR!" displays
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Accessibility**: Full keyboard navigation and screen reader support
- **Pirate Theme**: Beautiful nautical styling with golds, blues, and browns
- **Error Handling**: Pirate-themed error messages for invalid operations

## 🚢 Getting Started

1. **Clone the Repository**
   ```bash
   git clone https://github.com/your-username/pirate-calculator.git
   cd pirate-calculator
   ```

2. **Open in Browser**
   Simply open `index.html` in any modern web browser. No installation required!

3. **Start Calculating**
   Use the calculator for regular arithmetic operations or discover the hidden pirate mode!

## 🗺️ How to Use

### Basic Operations
- Click number buttons (0-9) to input numbers
- Use operation buttons (+, -, ×, ÷) for calculations
- Press `=` to get results
- Use `C` to clear all or `⌫` to delete last digit
- Click `.` for decimal numbers

### Keyboard Support
- **Numbers**: 0-9
- **Operations**: +, -, *, /
- **Calculate**: Enter or =
- **Clear**: Escape or C
- **Delete**: Backspace
- **Decimal**: . or ,

### 🏴‍☠️ Pirate Mode
1. Enter the sequence `7734` on the calculator
2. Watch for the pirate mode indicator to appear
3. All calculations now show "ARRR!" for 1 second before displaying results
4. Press `Clear` twice to exit pirate mode
